## Agent Harness 是什么
一句话：**Agent 是大脑，Harness 是身体。**
```
┌─────────────────────────────────────────────────┐
│                 Harness (身体)                    │
│                                                   │
│   ┌─────────┐    ┌──────────┐    ┌───────────┐  │
│   │  I/O    │    │  工具运行时 │    │  安全/护栏  │  │
│   │ 用户输入  │    │  sandbox  │    │  guardrails│  │
│   │ 输出展示  │    │  超时/权限  │    │  校验/兜底  │  │
│   └────┬────┘    └─────┬─────┘    └─────┬─────┘  │
│        │               │                │         │
│   ┌────┴───────────────┴────────────────┴──────┐  │
│   │           状态管理 / 可观测性                 │  │
│   │     checkpoint · tracing · metrics         │  │
│   └──────────────────┬────────────────────────┘  │
│                      │                           │
│              ┌───────┴───────┐                    │
│              │  Agent (大脑)  │                    │
│              │  LLM · 推理    │                    │
│              │  规划 · 决策   │                    │
│              └───────────────┘                    │
└─────────────────────────────────────────────────┘
```
Harness 要干的活：
| 职责 | 含义 |
|------|------|
| **I/O 管理** | 接收输入、格式化输出、流式展示 |
| **工具运行时** | 工具注册、执行、超时控制、权限隔离 |
| **状态持久化** | checkpoint、断点恢复、线程管理 |
| **可观测性** | tracing、日志、指标 |
| **安全护栏** | 输入校验、输出过滤、异常兜底、熔断 |
| **配置管理** | 模型选择、参数、环境切换 |

**骨架完整，该有的层都有。**
### ❌ 缺的

|------|------|--------|

| 配置外置 | `MAX_RETRIES` 硬编码 | 抽到 `config.yaml` |
| 流式输出 | 无 | 接真 LLM 后加 `astream_events` |
